# Online Quiz Platform 🧠🎯

An interactive **Online Quiz Platform** built using **React + Vite** that allows users to log in, attempt quizzes, view results, and check leaderboards. The platform also includes protected routes and an admin dashboard.

---

## 🚀 Features

- 🔐 User Authentication (Login & Protected Routes)
- 📝 Quiz Attempt System
- 📊 Results & Score Calculation
- 🏆 Leaderboard
- 🧑‍💼 Admin Dashboard
- ⚛️ Modern UI using React
- ⚡ Fast development with Vite
